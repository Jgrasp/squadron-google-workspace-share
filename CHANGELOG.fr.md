# Nouveautés

## 0.3.0 · 2026-11-16

- L’extension a son logo, affiché aussi sur l’entrée Partager avec l’équipe.

## 0.2.1 · 2026-11-13

- Arrêter le partage n’échoue plus quand Google refuse de supprimer le projet Apps Script : le lien est coupé et le projet reste dans votre Drive.

## 0.2.0 · 2026-11-13

- Un sous-agent sur Sonnet fait le partage dans la conversation de l’artifact, avec sa progression dans le panneau Artifacts.
- Les artifacts partagés sont nettoyés au bout de 90 jours par défaut, réglable dans les réglages de l’extension.
- Le lien partagé est celui de votre domaine, qui s’ouvre même quand le compte Google par défaut du navigateur est un autre.

## 0.1.0 · 2026-11-12

- Première version : partage un artifact html avec votre domaine Workspace en app web Google Apps Script, avec un état que tout le monde modifie ensemble.
